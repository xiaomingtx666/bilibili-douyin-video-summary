# Bilibili & Douyin 视频总结 Skill

这是一个 Cursor Skill，可以自动总结 Bilibili 和抖音视频的内容。

## ✨ 功能

- 提取 Bilibili 视频字幕
- 提取抖音视频字幕
- 支持 ASR 语音识别（需要配置 API Key）
- 生成视频内容总结

## 📦 安装方法

### 方法一：直接下载
1. 下载 `SKILL.md` 文件
2. 放到 `~/.cursor/skills/bilibili-video-summary/` 文件夹
3. 重启 Cursor

### 方法二：克隆仓库
```bash
git clone https://github.com/xiaomingtx666/bilibili-douyin-video-summary.git
cp -r bilibili-douyin-video-summary ~/.cursor/skills/
